FrameSolve 3D v1.0

产品：FrameSolve 3D 梁 / 杆单元建模求解
单位：同济大学
作者：任辉龙
邮箱：hlren@tongji.edu.cn
语言：中文 / English，可在界面顶部切换

使用方法：
1. 解压 FrameSolve-3D-v1.0-browser.zip。
2. 双击文件夹中的 index.html。
3. 推荐使用新版 Microsoft Edge、Google Chrome、Safari 或 Firefox 打开。

说明：
- 本发布包是纯静态网页，不需要安装 Node.js。
- 请保留 index.html 与 assets 文件夹在同一目录中。
- 如果浏览器安全策略或路径权限导致无法打开，可把整个文件夹复制到桌面后再双击 index.html。

English:
- Product: FrameSolve 3D frame/bar element modeling and solving.
- Language: Chinese / English, switchable at the top of the interface.
- Usage: unzip the package and open index.html in a modern browser.
